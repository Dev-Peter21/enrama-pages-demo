# Enrama Pages demo

Synthetic test site for Enrama R04. The client builds with Enrama 0.1.0 from PyPI.
The Client Pages workflow builds on pull requests and pushes to main. A manual
run from main waits for the github-pages environment approval before publishing.

See the [R04 contract](https://github.com/Dev-Peter21/enrama/blob/f6c9359c933dc3823e69cb3d44df48f2842c9441/docs/deployment.md#r04-github-pages-recipe-contract).
